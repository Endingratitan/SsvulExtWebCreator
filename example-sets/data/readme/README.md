# 项目名

由 data/readme/README.md 平铺输出到 output 根目录（readme=1 时）。

![项目图](@data/img/logo.png)

## 特性

- 静态站点生成：JSON 配置 → 页面树 + 资源
- markdown 渲染：simple/strict 双模式、脚注、目录、LaTeX 定界符
- 代码高亮引擎链：simple（构建期）/ hljs（客户端）+ U1 词表扩展
- 代码块外壳定制（code-ui）：items 开关 + CODEUI 逃生舱 + 复制按钮
- 离线模式：bucket 镜像本地替换

[bucket 图](bk/img/logo.png) 演示 readme 中的 bucket 引用在深度 0 的替换。
